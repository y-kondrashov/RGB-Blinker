# RGB Blinker

Невеликий проєкт на Arduino framework для ESP32-S3, який почергово блимає червоним і синім світлодіодами. Він підходить як базовий приклад роботи з GPIO у PlatformIO.

## Як працює

Після запуску мікроконтролер повторює цикл:

1. Вмикає червоний світлодіод на GPIO 4 на 300 мс, вимикає його та виводить `Red`.
2. Вмикає синій світлодіод на GPIO 5 на 300 мс, вимикає його та виводить `Blue`.

Повідомлення надсилаються через `printf` і доступні в серійному моніторі на швидкості 115200 бод.

## Обладнання

- ESP32-S3 DevKitM-1 або сумісна ESP32-S3 плата.
- Червоний світлодіод, підключений до GPIO 4 через струмообмежувальний резистор.
- Синій світлодіод, підключений до GPIO 5 через струмообмежувальний резистор.
- Спільний GND для плати та світлодіодів.

Переконайтеся, що обрані GPIO доступні на вашій платі. Якщо використовуєте інші контакти, змініть `ledPin_Red` і `ledPin_Blue` у `src/main.cpp`.

## Збірка та завантаження

Потрібні [Visual Studio Code](https://code.visualstudio.com/), розширення [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) та USB-драйвер для вашої плати (якщо він потрібен).

1. Відкрийте папку проєкту у VS Code з PlatformIO.
2. Під'єднайте плату USB-кабелем з підтримкою передавання даних.
3. Зберіть проєкт командою `pio run` або кнопкою **Build** у PlatformIO.
4. Завантажте прошивку командою `pio run --target upload` або кнопкою **Upload**.
5. Відкрийте серійний монітор командою `pio device monitor` або кнопкою **Monitor**. Швидкість — 115200 бод.

За потреби вкажіть порт у `platformio.ini` через `upload_port` і `monitor_port`.

## Налаштування плати

`platformio.ini` використовує PlatformIO платформу Espressif32 версії `~6.8.1`, плату `esp32-s3-devkitm-1` та Arduino framework. Додаткові параметри задають 16 MB flash і 8 MB PSRAM у режимі `qio_opi` для заявленої конфігурації ESP32-S3-N16R8. Перевірте, що саме ваша плата має таку конфігурацію пам'яті: ці параметри потрібно змінити для інших модифікацій.

## Структура

```text
├── include/        # Заголовкові файли проєкту
├── lib/            # Локальні бібліотеки
├── src/main.cpp    # Логіка блимання світлодіодів
├── test/           # Місце для тестів PlatformIO
├── .gitignore      # Ігноровані артефакти збірки та локальні файли
└── platformio.ini  # Налаштування середовища PlatformIO
```

У папках `include/`, `lib/` і `test/` зараз є стандартні файли-пояснення PlatformIO; окремі бібліотеки чи тести ще не додані.
